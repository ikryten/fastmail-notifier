Fastmail Checker

Unread-mail badge and preview window for Fastmail.

Connection

Create one in Fastmail under Settings → Privacy & Security → API tokens, with the Mail scope. Read-only works for the badge, but marking read and moving to Trash need read-write.

The token is stored unencrypted in this browser profile, like any extension setting. If this machine is ever compromised, revoke it here — it takes effect immediately.

Checking

Minimum 30 seconds. One small API request per check.
